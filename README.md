# SQL-Data-Warehouse-1st-Project
In this project I made a Data Warehouse for a little store in my neighborhood that is made with the as the following:

## Porpoise: 
To demonstrate a comprehensible the building of a Data Warehouse that incorporates data ingestion, data cleansing and generates data
that can help a company or in this case a little store to get analytics of sales, prices, etc so the company could make decisions 
based in real data

-------------------------------------------------------------------------------------------------------------------------------------------

## Knowledge to demonstrate:
A medium-high SQL Server use ability and complex SQL Data concepts that can demonstrate that I can apply them in 
real projects with the best and updated practices of a Data Engineer.

------------------------------------------------------------------------------------------------------------------------------------------

## Project Requirements:

### 01: Build a Data Warehouse (Data Engineer)

I have to build a modern Data Warehouse using SQL Server to consolidate sales data, enabling analytical reports and informed management making.

#### Specifications:
- **Data Sources**: demonstrate the importation of data from Data CSV Files (ERP & CRM).
- **Data Quality**: demonstrate a resolution of data quality issues using cleansing or substitution of Data prior to analysis.
- **Integration**: combine the importations of sources of data into a single user friendly data model that can be use for analytics queries.
- **Scope**: will be focused in the latest Data sets (Historization will not be required).
- **Documentation**: it need to provide clear documents about the data model for business stakeholders and analytical teams.
---------

### 02: Analytics and reporting (Data Analytics)

To develop a SQL based analytics to reveal real and updated insights that can help and empower stakeholders and decision making persons with Key metrics such as Customer behavior, Performance of products, Sales trends, etc.
